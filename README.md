# arlengros-art

## Цели проекта
Этот репозиторий содержит исходный код персонального сайта‑портфолио Arlen Gros. Сайт позволяет знакомиться с моими проектами и даёт возможность посетителям оставлять обратную связь.

## Стек
- [Next.js](https://nextjs.org/) и React
- TypeScript
- Node.js

## Развертывание
1. Установите Node.js версии 18 или новее.
2. Установите зависимости фронтенда:
   ```bash
   cd frontend
   npm install
   ```
3. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу http://localhost:3000.
4. Сборка и запуск production‑версии:
   ```bash
   npm run build
   npm start
   ```
