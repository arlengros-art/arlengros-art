## Развёртывание в Docker

Для локального запуска сервисов используйте `docker-compose`:

```bash
docker-compose up --build
```

Команда соберёт образы для `frontend`, `backend` и базы данных и запустит их.

Для остановки и удаления контейнеров:

```bash
docker-compose down
```
