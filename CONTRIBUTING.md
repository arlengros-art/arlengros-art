# Руководство по участию

Спасибо за желание внести вклад в проект!

## Как предложить изменения
1. Форкните репозиторий и создайте ветку для своей задачи.
2. Выполните изменения и напишите понятное описание коммита.
3. Убедитесь, что все проверки проходят (`npm test`).
4. Откройте pull request с описанием изменений.

## Код-стайл
- Используйте TypeScript для фронтенда.
- Отступы — 2 пробела.
- Имена переменных и файлов пишите в `camelCase` или `PascalCase` для компонентов.
- Перед коммитом форматируйте код (например, с помощью `prettier`).

## Контакты
Если возникли вопросы, создайте issue или свяжитесь со мной напрямую.
